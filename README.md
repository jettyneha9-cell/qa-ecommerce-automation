# QA E-Commerce Automation

End-to-end automation testing project for an e-commerce demo application using Playwright and TypeScript.

## Project Overview

This project covers core QA automation scenarios for a sample e-commerce flow, including:

- Login validation.
- Add to cart and remove from cart.
- Checkout flow.
- Form validation.
- Responsive testing.
- Cross-browser execution.

## Tech Stack

- Playwright
- TypeScript
- Node.js
- GitHub Actions
- Git
- VS Code

## Test Scenarios

### Login Tests
- Valid login.
- Invalid login.
- Locked-out user login.
- Empty field validation.

### Cart Tests
- Add single item to cart.
- Add multiple items.
- Remove item from cart.
- Open cart page.

### Checkout Tests
- Complete checkout with valid data.
- Field validation during checkout.

### Responsive Tests
- Desktop view.
- Mobile view.
- Tablet view.
